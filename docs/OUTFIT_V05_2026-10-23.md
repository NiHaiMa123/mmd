# 0.5：透明衣料接触诊断与 Blender 物理诊断修正

本轮沿用 0.4 的衣服、手套、丝袜和鞋子几何，修正诊断工具。仍需视觉与原生 MMD 动力学验收，不能宣布完整换衣完成。

## 透明叠层

来源手套的“服+jinshu”在手部与“服”重合，但这一带基础贴图 alpha 为零。单独渲染确认该区域不可见。此前最近表面检测把透明叠层也当作接触表面，既可能误报，也可能遮蔽其他表面的问题。

新增 src/visibility.py：只对标准 MMD 基础 alpha 连接和直接 UV 坐标进行保守过滤。检查整个三角面 UV 包围矩形及双线性邻域，支持重复 UV；存在任何非零或非有限 alpha 就保留。未知材质、坐标、插值以及受主 UV 形态键影响的面保留。它只影响接触诊断，模型面、材质、权重和形态键不变，异常拉伸仍检查全部衣料。

每个动作帧同时记录过滤结果与 raw_geometry，两者分别在同一个静态模型上建立参考，不能用过滤后参考解释原始计数。透明过滤不保证降低穿出比例，也不能把最近表面符号变化当作可见穿模的证明。

对 0.4 最终 PMX 的 24 帧复查：

- 衣料 53,346 面，其中 9,476 面可确认透明：服 292、服+jinshu 9,184；43,870 面仍参与接触检测。
- 主 UV 形态键涉及 4 个顶点，其关联面保留。
- 未过滤最高比例 1.007%，过滤后最高 1.137%，最差抽样帧为 61；每帧检测 8,445 个身体采样点。
- 大幅/严重异常伸长边均为 0。剩余点仍需按部位看图，不能据统计宣布无穿插。
- 数据：outputs/outfit_v05_visible_contacts/report.json；逐顶点诊断：outputs/outfit_v05_visible_regions/report.json。

## 碰撞排除与循环

MMD Tools 原 builder 只在指定距离内生成禁止碰撞约束。新增距离参数计算覆盖每一对 PMX 禁止碰撞刚体，再用全部刚体对校验实际过滤，发现任何差异就失败。

模式 0 跟随刚体原本会通过父骨、静音 Child Of 约束和动态骨的追踪约束形成反馈。即使约束静音，Blender 仍可能保留依赖边。诊断先在物理构建前记录动画驱动的世界变换，再构建原生 MMD Tools 约束、移除所有残留静音的 mmd_tools_rigid_parent，并安装不依赖骨架的跟随轨迹。要求全新未构建导入，拒绝从已运行仿真取样。

这会省略次级物理回传到模式 0 跟随刚体的效果。本机 4 根反馈骨记录在 setup.kinematic_bake.feedback_bones，不能据此声称与原生 MMD 等价。完整禁止碰撞约束也增加内存与构建时间，本机约两分钟完成构建。

先前连续 1–121 帧试验在 outputs/outfit_v05_relations_fixed/：356 刚体、63,190 对、预期/实际允许碰撞均 17,753 对，全部及动作附近过滤差异为 0；构建中仍有 14 个临时循环警告，PHYSICS_SETUP_READY 后没有再报告循环。模型实际移动，没有大幅/严重异常伸长。最终组合复查另存 outputs/outfit_v05_physics_final/，不覆盖 0.4 数据。

## 使用

安装包 dist/mmd_outfit_bridge-0.5.0.zip，inspect / fit / validate 接口不变。普通动作回执自动包含透明过滤与原始对照。物理诊断命令见 OUTFIT_AGENT_WORKFLOW.md，辅助源码脚本不随安装包作为独立命令分发，所用引擎包含在 ZIP 中。
