## 修正依据

### 手套、丝袜

目标皮肤在 UV 接缝处分开，位置相同的顶点法线却不同。直接沿各自法线外扩，左手有 286 组位置会张开，最大约 1.158 mm；这就是静态手指侧面露肤细线的重要原因。

现在同位置的顶点共享外扩位移，并做有上限的角部补偿，保留原 UV、权重和所有形态键。最终两手 588 组、双腿 187 组位置共享位移。袜层原先可能产生的最大接缝距离约 0.565 mm。

手部 UV 采样限制在对应手指/手掌，且每个目标顶点固定使用同一个采样域，避免相邻三角面在指根选择不同图表。最终没有跨域回退，也不需要新增 UV 拆点。通用的显式拆点保护仍保留：如果新 UV 接缝确实需要拆点，先复制坐标、法线、全部权重和形态键，再进行 PMX 导出，严格重导入检查没有放宽。

这改善了露肤缝和错域采样，不代表手套图案、腕口和所有握拳动作已经完美。原 UV 最近面参考最大距离：手部约 23.73 mm，袜层约 34.02 mm；图案拉伸及细小纹理接缝仍须看图。

### 胸衣

径向位移场分箱后，原控制点会偏离分箱中心，Gaussian 插值因而略微衰减。现在补偿此衰减，同时让各衣料层仍共享同一径向位移场。

最终静态设定间隙违反点由 160 降为 0，最小已测间隙约 6.000 mm。另有 2,972 个候选点不在皮肤参考覆盖内，保持原位；它们不能被算作已验证。这个数值检查不是动画或三角面无穿插证明。

### 服装物理

核对本机已安装 MMD Tools 的属性定义及 PMX 导入、导出源码后，确认 `mmd_rigid.collision_group_mask=True` 表示禁止碰撞；原始 PMX 文件位 True 表示允许碰撞。旧代码混淆两者。0.4 修正服装组映射、身体侧允许/排除关系及诊断解释，更新了 36 个目标碰撞体。

迁移 110 个服装刚体、182 个服装关节，没有真正缺失的服装关节端点。此前“跳过 34 个关节”实际是未选中的来源部件关节，现单独记录 `joints_unrelated=34`，不再误报为服装迁移失败。

旧 Blender 层近似/直接写骨骼代理会把模式 2 也当作完整位置驱动，已观察到飘带拉飞。QA 改为调用已安装 MMD Tools 的 build_rig，使用其父子关系、模式 1 变换约束和模式 2 旋转约束，并连续步进。增加物理过程中的异常边长检查，保留碰撞过滤差异报告。

这仍是 Blender Bullet 诊断。当前模型会产生 14 个依赖循环警告，MMD Tools 的距离限定排除约束也有过滤差异；不能据此宣布原生 MMD 物理通过。旧代理数据不能继续作为动态验收依据。
