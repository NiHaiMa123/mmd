# 保留抱拳与接触意图：分类、研究和修正方案

后续实测更新：已在限定拓扑修复实时关节／衣料时刻偏差，增加双关节头部避让＋随动双层衣料、六关节双手持续接触保持回归。证据见 [实时与双手接触记录](CONTACT_LIVE_AND_BIMANUAL_2026-10-27.md)。这些是简化用例，真实角色抱拳、完整衣料与 15 秒系统尚未通过；下文早期“实时仍失败”保留为研究历史。

## 后续澄清：目标是一整套动态防穿插系统

用户再次明确，范围包括整个人体、所有服装层、有意接触、普通扫碰及空间不足时的动作反馈，不限于抱拳。抱拳仅作为其中一个回归用例。

补充核实了两个已经发布代码的统一物理底座，不能再将候选范围局限于独立衣料插件：

- [libuipc 官方源码与示例](https://github.com/spiriMirror/libuipc)：统一 IPC 中耦合 ABD 刚体、FEM 软体、衣料与线，含关节和软变换约束；README 给出 Windows/Linux Python wheels、机器人手、布层和关节示例。它也明确非穿透保证依赖合法初态与成功求解，完整自动微分仍在开发中。
- [Genesis IPC 耦合器的版本文档](https://genesis-world.readthedocs.io/en/v1.3.0/user_guide/theory/couplers/ipc_coupler.html)：已提供 `pyuipc` 接入、FEM.Cloth、刚体及 `two_way_coupling=True`，明确接触力可返回 Genesis 刚体；有 `examples/IPC_Solver/ipc_objects_falling.py` 完整小样。此示例并不证明 PMX 蒙皮、VMD 动作意图和人体关节已自动适配。
- [Newton SolverVBD 官方文档](https://newton-physics.github.io/newton/latest/solvers/vbd.html)：衣料、软体、有关节的刚体及接触在同一求解循环处理；[完整开源工程](https://github.com/newton-physics/newton)提供 Python 接口和示例。官方明确标为实验性，不能推断所有组合都已稳定或具有 IPC 同等的防相交条件。

随后已实际安装并运行 Genesis＋libuipc，完成单关节、双层衣料的受限输出小样；原始实时骨架仍有偏差，不接受，尚未接入完整角色。具体证据与限制见[底座实测](CONTACT_BACKEND_PROBE_2026-10-27.md)。Newton 尚未本机运行。当前没有核实到可以直接导入任意 PMX/VMD，便自动保持原动作含义、处理全部身体／衣服接触并输出合格成片的现成成品。

完整开发路线应优先复用现有耦合物理底座，再实现 MMD 桥接、蒙皮表面与关节代理对应、按意图跟踪动画的控制／优化、初始交叉整理与复验。规定运动的身体若被完全硬锁，打开双向耦合也不能让原骨骼自动让路。

底座筛选应在同一个系统里覆盖：普通扫头／躯干、偶然双肢碰撞、有意手部接触、身体带动衣片、多层衣料挤压、空间不足后动作调整。必须把高精蒙皮与物理代理分别验收；代理无交叉不等于实际皮肤与服装无穿透。

## 用户反馈与当前结论

用户明确否决 `body_contact_v1` 的交叉抱拳：修正后已经不是原手势。
该候选只通过了既定身体区域的离散几何检查，动作验收失败；不得将
“899 个采样无交线”当作正确动作或正式成片的通过条件。
原文件、原 Action 和几何检查数据保留用于对照，不改写历史测量。
`acceptance.json` 及其生成脚本新增 `accepted_as_motion_correction=false`
与 `semantic_acceptance.gesture_preservation=FAIL`。

本轮搜到的研究支持把“应保留的接触”和“意外碰撞”分别建模。
下面的插件方案是依据研究提出的本项目设计，尚未实现或验证新的抱拳修复。

## 分类不是只按碰撞的两个部位

同样是手与头靠近，可能是错误扫入，也可能是扶额。仅凭距离、交线数或
相对速度不能可靠推断意图。优先采用正确源动作的接触关系、用户标注和
接触开始／保持／释放的时间段；穿模后的目标角色不能独自充当正确参考。

| 情况 | 保留什么 | 首选响应 | 验收重点 |
| --- | --- | --- | --- |
| 非故意的肢体扫入头／躯干 | 原头／躯干动画、肢体运动的大致方向 | 主体沿原轨迹；手臂经 IK 沿外表面绕行 | 身体表面与整条手臂无穿透，接触前后连续 |
| 非故意的两肢互撞 | 原节奏、关节限位、支撑／持物关系 | 按可动性分摊相对法向修正 | 不新增抖动、肘翻折或脚滑 |
| 抱拳、合掌、抱臂等有意接触 | 指定接触区、双手相对朝向、交叉层次与接触时序 | 双手联合约束、肘部极向约束、整段动作优化；必要时重新 K 关键姿态 | 接触仍成立且手势可辨认，不能用分开双手换交线清零 |
| 身体或其他衣服扫过软衣料 | 身体动作意图、衣片连接、材质性质 | 厚度接触＋摩擦＋弹性／惯性；衣料可滑、被推、被带动 | 衣料对身体及衣料对衣料接触，不拉成薄片、不自动黏死 |
| 空间或可达性确实不足 | 用户指定的动作含义 | 反馈到局部动作窗口，先调整低优先级自由度 | 找不到同时保留接触与避碰的解就失败并请求重建姿态，不能静默拆手势 |

“主体优先不动”在这里指优先保持其原有动画，不是把跳舞中的头和躯干
固定到世界坐标。两肢也不总是各退一半：接地脚、持物手和有意接触会改变优先级。

## 已读取的研究及适用边界

### 1. 接触感知动作重定向

[Contact-Aware Retargeting of Skinned Motion，ICCV 2021，作者项目](https://sites.google.com/umich.edu/camr)
与[论文](https://arxiv.org/abs/2109.07431)：区分需要保持的自接触、接地与需要减少的穿插，
利用角色几何优化重定向。它直接对应手触手／头／躯干的语义保留。
有学习网络及骨架适配要求，不能把论文方法直接说成已接入的 MMD 插件。
本轮未在作者项目页核实完整可用的代码发布。

### 2. 不同体型下的相对关系与平滑

[ReConForM，CGF / Eurographics 2025](https://arxiv.org/html/2502.21207v1)：
以蒙皮表面关键点的距离、方向和法向投影描述交互，随接近程度调整重要性，
并联合考虑运动平滑。适合借鉴为本插件的接触语义目标，而不是继续只惩罚交线。
第 6.3 节也展示约束不可兼得的情况，需要明确取舍；稀疏点目标不等于全表面 CCD 保证。
本轮未核实可直接复用的完整官方实现。

### 3. 交叉与缠绕的空间关系

[Spatial Relationship Preserving Character Motion Adaptation，SIGGRAPH 2010，作者机构页面](https://researchportal.northumbria.ac.uk/en/publications/spatial-relationship-preserving-character-motion-adaptation/)
用 Interaction Mesh 保持身体部位间的空间关系，覆盖近距离交互、接触和缠绕。
对交叉双臂／抱拳的启发是：保留成组的关系，而非把左右臂当成完全独立的障碍。
空间关系表示仍需配合实际蒙皮接触和时间连续性检查。

### 4. 主次与优先级

[Set-Based Tasks within the Singularity-Robust Multiple Task-Priority IK Framework，2016](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2016.00016/full)
讨论把避障、关节范围等不等式任务纳入分层 IK。它支持“任务优先级”和
“只在需要时激活避障”的设计，不是用于本模型的现成解算器。
本项目可据此采用分层约束 IK／QP，避免只调一个总权重导致主任务悄悄被牺牲。

### 5. 衣料被扫动：法向接触与切向摩擦

[An Implicit Frictional Contact Solver for Adaptive Cloth Simulation，SIGGRAPH 2018，作者项目及代码入口](https://www-users.cse.umn.edu/~lixx4611/contact_friction.html)
研究衣料—身体和衣料—衣料之间的库仑摩擦与黏滑。
[C-IPC，SIGGRAPH 2021，作者项目](https://ipc-sim.github.io/C-IPC/)
进一步结合厚度、应变限制和保守连续碰撞检测，处理薄层接触及摩擦。
这些研究对应真实接触响应；不能把衣料简单逐点推到法线外侧或固定跟随骨骼来替代。

[DiffCloth，TOG 2022，官方代码](https://github.com/omegaiota/DiffCloth)
提供含干摩擦接触的可微模拟，以及辅助穿衣等轨迹优化示例；仓库列出的测试环境是
Ubuntu / macOS，不能直接承诺在当前 Windows Blender 中即插即用。

### 6. 让衣料反过来影响有关节的身体

[DiffClothAI，IROS 2023，作者项目](https://sites.google.com/view/diffsimcloth)
明确研究衣料与关节刚体的双向可微耦合及防相交摩擦接触，是“挤不下就改动作”
的重要相关方向。但机器人关节刚体与本模型的蒙皮表面、MMD 扭转辅助骨仍需适配。
代码可用性不能仅凭论文推断：截至本轮查阅，[SoftMAC 官方 README](https://github.com/minliu01/SoftMAC)
仍注明其底层 DiffClothAI 未开源，不能把该库的部分开源耦合代码称为完整即用衣料求解器。

另核实 [R2ET，CVPR 2023，官方代码](https://github.com/Kebii/R2ET)：已有神经重定向实现，
涉及专用数据、PyTorch / CUDA SDF 等依赖。其 README 在 2025-01-12 记录过抖动修复，
不能把论文中另一版实现的抖动评价直接套到当前代码，也不能不经本模型复验便宣称可用。

## 本项目的具体修正设计（尚未实现新解）

### 普通擦碰：阻止向里，保留掠过

在接触对中令 n 从主体表面指向运动肢体，使用相对速度
`v_rel = v_limb - v_surface`，而非只看肢体的世界速度。
工程上可限制 `n · v_rel >= (clearance - gap) / dt`；只补足缺失的法向速度，
保留原切向分量。这是局部平面近似，不是完整避碰算法；法线应从首次接触和
正确外表面连续跟踪，不能在已穿到另一侧后反复采用跳变的最近面法线。

随后通过整条运动链的雅可比／IK修改骨骼，保留骨长与关节限位；检查上臂、
肘、手掌的实际蒙皮，不能只移动手腕或直接挪皮肤顶点。
加入前后帧的速度／加速度平滑及连续碰撞检查，才可能形成自然的表面绕行。
对等两肢分摊的是同一接触对的相对修正，不是各自计算一次独立推力。

### 抱拳：先保住成组关系，再找避碰路径

1. 从可信原动作或人工关键姿态标注接触区、掌／拳朝向、左右前后层次和时间段。
   不以错误目标动作的“离得近”自动认定接触，也不把整个阶段锁成一个死姿势。
2. 建立双手相对位置／朝向与表面接触区约束，保留原手指动作；允许必要的接触滚动。
3. 先移动双手组成的整体目标，配合双臂联合 IK、肘部极向和合理肩部自由度。
   一只手不得为了避胸独自甩开另一只手。
4. 对进入—交叉—保持—分开的整个窗口联合优化，保持肘部解分支和交叉层次。
   若初始就处于错误侧或局部最小值，使用少量重新 K 的引导姿态建立绕行路径。
5. 无交线、保留接触、相对掌向／手指形状、动作节奏、关节范围、平滑性分别验收，
   再输出正侧背近景。找不到兼顾的解时明确失败，不把拆散双手当作通过。

### 软衣料：先允许衣料响应，再判断是否需要动作让路

法向接触防止穿透，切向摩擦决定带动与滑动程度，同时解衣料弹性、弯曲和惯性。
接触不等于立即黏住；摩擦也不意味着扫过后永远粘在手上。
先解衣料—身体和衣料—衣料接触。只有附着可达性、厚度／应变或局部拥挤等
约束共同表明不可行时，再修改低优先级动作窗口并重算。
软附着偏差大本身不能作为空间不足的判据。

## 下一项实际工作

以原动作的交叉抱拳窗口作为单独的失败用例，先标注可信接触与朝向，建立
双手联合约束和肘部解分支，再生成短段多角度对照。
该段手势验收通过后才继续完整衣料解算；本轮没有生成新的已修复抱拳文件。
