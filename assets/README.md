# 本地输入资产

本目录用于放置**本地私有**的 MMD 资产，**默认不提交到 Git**（见 `.gitignore`）。

## 需要的文件

| 约定名 | 说明 | 本机测试用 |
|---|---|---|
| `source.pmx` + 同目录贴图 | 来源角色（含要拆走的衣服） | 刻晴.pmx |
| `base.pmx` + 同目录贴图 | 固定素体（穿衣服的目标身体） | 达妮娅.pmx |
| `motions/*.vmd` | 动作测试集（P2 用） | 你的笑容…vmd |

## 贴图路径约定

PMX 里的贴图引用是**相对 PMX 所在目录**的，所以请保持：

```
assets/
  source.pmx
  source_tex/     # 贴图放在同级子目录时，PMX 内引用需写成 source_tex/xxx.png
  base.pmx
  base_tex/
  motions/
```

如果贴图散在多个目录（`tex/`、`sph/`、`toon/`），保持与原模型包一致的相对结构即可，
导入时程序按 PMX 同级相对路径解析。

## 注意事项

- 第三方模型只在本机使用，不要提交到公开仓库。
- 源文件请保持只读；程序一律「导入 → 另存」，不修改原 PMX。
