# 算法与验收

1. 最终蒙皮 BVH broad phase，再逐候选三角形检查真实非共面穿越；接触和共享解剖边界不直接算穿越。
2. 几何焊接确认闭合的区域补充内部点采样，避免完全包住却没有交线。开口区域和共面重叠仍有盲区。
3. 双向构建移动顶点／对面三角形及反向特征，沿表面法线设置毫米级间隙。
4. 有限差分 Blender 实际蒙皮，得到控制骨旋转的接触雅可比，做阻尼最小二乘投影。每步最多 3°、总偏移受限，初值也需受限；腕部补偿世界朝向。主骨不参与该修正自由度。
5. warm start、短窗口平滑后重新投影；失败试零初值与受限确定性多起点，仍失败则 UNRESOLVED。
6. 原 Action 为 NLA REPLACE 基层，另建 COMBINE 四元数修正层；保护窗口影响为 0，进出渐变。按失败子帧增加修正键并重查。

必须复查实际 NLA 混合后的网格：完整偏移解通过，乘上进出保护段的渐变系数后可能再次穿插。实测第 250.25–255.75 帧出现 22 个这类失败样本。不能自动扩大保护窗口掩盖失败；需要接触阶段与轨迹约束的联合过渡，若保持原保护动作与连续无穿插不可兼容，要明确报告。

局部关节折叠与远距离肢体扫碰分开诊断。先比较同姿态 POSE 与 REST，静置无交线、弯曲后出现的腕／髋折叠常与蒙皮有关；有限释放腕部旋转在实测关键帧可修复腕部折叠。双四元数和平滑可能改善外观但不是避碰约束。本案例髋部试验中二者仍有交线，4 厘米足部偏移也未通过。`ik_projector.py` 与 `joint_surface.py` 只属实验接口，不默认改落脚或皮肤；应继续增加合理的关节形态／权重适配、接触约束和低应变条件，不能把失败写成成功。

8 毫米局部皮肤位移投影也未解决髋部测试帧，并出现最高约 1.81 的边长比，不能继续无限增大皮肤偏移。该例需要结合关节形态适配与动作空间重规划。可研究 [SMPLify-X 的碰撞损失接口](https://github.com/vchoutas/smplify-x/blob/master/smplifyx/fitting.py)和 [torch-mesh-isect](https://github.com/vchoutas/torch-mesh-isect)的锥形距离场思路；其代码带专门许可条款，未复制、安装或打包为本插件依赖。

这是实际蒙皮的局部运动学投影原型，未实现完整 TrajOpt、全局最优、有意接触重建或 CCD；默认求解未覆盖所有检测对。

28 对身体语义区域检测也不包含同一区域内部自交。可用 self_collision_regions 启用额外三角检测，但需显式处理指甲／皮肤等预期嵌入的建模接口；不能把未做的同手手指、同腿内部检查默认为通过。

迁移验证包含独立英文骨架和厘米单位同尺度场景。实测手／闭合头部 20 交线降为 0，完整包含反例检测到 42 个内部样本，厘米场景也通过。它证明接口可迁移，不代表任意 MMD 自动适配。

验收至少记录配对／忽略面、未映射数、采样和失败帧；主骨世界矩阵差、保护段网格差；原 Action 曲线哈希；最大角度及帧间跳变；正侧背画面。几微米 NLA 舍入可注明容差，不能以此掩盖毫米级变形。

参考：[TrajOpt 官方文档](https://rll.berkeley.edu/trajopt/doc/sphinx_build/html/)与[论文](https://rll.berkeley.edu/~sachin/papers/Schulman-IJRR2014.pdf)提供轨迹优化、距离约束和连续检查思路；[JAX-IK 原代码](https://github.com/hvoss-tech/JAX-IK)提供 SDF 自碰接口，但本包未安装或验证该库。
