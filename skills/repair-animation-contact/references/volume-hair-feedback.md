# 体积发束与动作反馈实验

固定根挡住手臂、宽发片在代理之外，或逐帧修正产生跳变时，使用此分支。稳定插件仍为 0.1.6；
随附 `assets/contact-experiments-20261030.zip` 是实验源码快照，不替换稳定安装，不自动启用侧栏入口。
解压后把其中 `addon/` 加入 Blender Python 的导入路径，读取 `experiment.json` 的运行依赖。

## 决策与输入

- 发片可有作者设计的静置自交，不能直接充当无自交物理对象。先生成覆盖原发片的合法闭合包络，
  四面体剖分应为正体积、外表面流形且无自交；本例是 325 点／864 四面体。
- 用 `tet_volume_binding.bind_volume(points,vertices,tets)` 计算显示点重心坐标。包络外点应报错；
  不靠负权外推。用 `deform_volume(binding,vertices)` 重建，检查原始点重建误差。
- 真实硬根来自原绑定证据。显示硬根所在四面体的所有顶点规定跟随头部，可保持重心插值后的精确附着。
  若约束不可行，改动作／初态；不要缩小硬根或关闭碰撞。
- 物理休止体积、合法显示初态、原始应变参考必须分别保存。扩展动画起点时，用原头锚点搬运休止体积。

## 时间共享动作修正

`spline_clump_feedback.solve_spline_clump` 接受已有实际网格、armature、身体 profile、发束 config、
合法显示坐标及输出目录。身体控制链和辅助扭转骨显式配置，发束按 `multiple-bundles.md` 映射。
共享时间 B 样条控制手腕位置、肘部旋转平面及材料扭转，原手掌世界朝向保持；
实际蒙皮有限差分雅可比、三角面内部见证、持续表面约束共同处理碰撞。

这是局部优化，可能不可行或陷入局部极小。不要照搬本例 10cm 位移／角度参数；
报告原动作与修正后的峰值速度、位移、朝向、骨长及接回。逐帧投影再平滑曾使峰值手速翻倍，已拒绝。
`linear_skin_playback` 只在源模型与原生前向蒙皮误差通过时加速；不支持的修改器应回退，最终用原生验收。

## 区分关节蒙皮折叠

手扫头已经避开，但相邻前臂／手掌仍有小交线时，先定位到三角面，判断是否为 LBS 收缩折叠。
用相同骨姿态比较原生 LBS／DQ。若只需很小的局部变化，可调用：

```python
from animation_contact_tools.local_volume_skin import bake_local_volume_skin
result = bake_local_volume_skin(
    mesh, arm, ids, mask, wrist_bone, cache_path,
    first=first, last=last, step=.0625, blend=1., fade=1.,
    namespace='WristVolume')
```

`ids`、`mask` 由角色适配器提供：本例用原手腕权重乘静置空间衰减，不改原权重。
mask 必须有限且在 [0,1]；函数仅支持一个原 LBS Armature，保持骨动作、权重和基础网格。
它是有窗口的采样蒙皮修正，不是碰撞求解器；局部／亚帧仍可能产生新交线，必须重新验。
不要直接全局开启 Preserve Volume，否则原身体与保护段会改变。

## 成熟物理后端与显示映射

PPF Windows 运行时需另外提供，解压在实验源码的 `tools/ppf/native`；原生 Blender 不自带。
参考官方 [PPF 项目](https://github.com/st-tech/ppf-contact-solver)。随附 `scripts/solve_ppf_hair_volume.py`
接收 `manifest.json`、`trajectories.npz`（cloth/body、三角面、四面体、pins、original_mapping），
绑定文件由适配器生成。角色工程导入／导出包装器尚未通用化，不能宣称一键换模型。

身体规定轨迹保持真实蒙皮覆盖；条件数不足的薄三角面可用
`condition_ppf_collision_triangles.py` 的小包围盒保守覆盖，不能直接删掉碰撞面。
适配过程保留 `volume_binding.npz`。接触豁免应为 0、允许相交关闭，记录真正生效的硬根、时间步和输出率。
薄面的几何法线在折叠时可能跳变，使盒角点互换；检测相邻朝向，必要时沿长轴平行输运横轴，
并在原轨迹关键时刻及额外插值时刻验证原三角形仍在盒内。不要跳过朝向检查强行运行。
本例内部 dt=.003s、120fps 输出，源动画仍是 30fps。

完整片段输入可能因规定轨迹过密而很慢。`trajectory_keys.reduce_trajectory_keys` 按最坏顶点误差
自适应选共享时间键；`reduce_ppf_body_keys.py` 只简化身体时间键，保留全部身体顶点／面及所有发根键。
本例 3593→2438 键，测得最大误差小于 0.1mm；这属于物理碰撞体的时间近似，原角色动作不变，
不能报告为精确皮肤规定轨迹，也不证明源采样之间的误差界。实际最终发片必须对原始角色网格复查。
改变时间步先在已知接触段做对照：本例 dt=.008s 的难段独立 289 样本也通过，耗时约减半；
这个值不是通用最优值，完整连续结果另验。

长任务可用官方检查点保存／续跑。`finished.txt` 也可能由保存退出产生，不能单凭 finished()
标记完成；须核对实际最后输出帧等于请求帧。`capture_ppf_prefix.py` 按官方顶点映射读取完成的前缀，
通用物理入口默认每 120 输出帧保存原生状态，并在完成时保存；中断后用真实状态恢复，不从点缓存假造速度。
状态显式为前缀，不能写成完整解算通过；不要假设原生输出的前几个点就是发束点。

用非负四面体重心坐标直接映射原显示发片，避免再叠一个无法控制误差的变形器。
以头部局部缓存回放，选区之间不重叠。REST 碰撞拓扑构建会临时停用测量位置节点，随后恢复，
避免已动画化的缓存覆盖静置蒙皮。

## 验收证据与边界

本例 238–252 帧动作＋局部皮肤独立 449 个 1/32 帧样本通过；236–254 帧真实动态发片
独立 289 个 1/16 帧样本：交线／包含／应变失败 0，边长比 .92293–1.06203，真实根误差约 .000569mm。
右束回归通过，原 10 Actions 与 231 形态键保持。没有以硬根通过代替柔性区验收。

完整 15 秒、全头与发束自碰尚未验收。PPF 对物理对象的 CCD 不证明显示网格连续无穿越；
离散通过、动作自然度、多角度画面、窗口接回及原数据保持应分别报告。失败样本不可删配对隐藏。
